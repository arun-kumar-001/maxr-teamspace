## Defaults chosen for open rules (change by editing here and telling the developers)

| ID   | Question                                               | Default                                                                                                                                                                                                             | Used by      |
| ---- | ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| D-11 | What is a "team"?                                      | A Team Lead's team is the employees whose `manager_id` is the Team Lead (direct reports, not recursive). "HR scope" is all employees.                                                                               | #8, #19, #35 |
| D-21 | Who can edit permissions?                              | The four roles are fixed. The permission catalog is defined in code and mirrored into the database by migration; roles get permissions only through a code change plus a migration (no editing screen in the MVP).  | #8, #27      |
| D-26 | Does "team" scope include the Team Lead's own records? | No. `team` is direct reports only. A Team Lead reads their own records through the `own` permissions (for example `attendance.read_own`). Out-of-scope single records answer 404, a missing permission answers 403. | #8           |
| D-27 | May a Team Lead export reports?                        | Yes, for their team only (`reports.export` with team scope), same as viewing. Staff have no report access. Every export is audited.                                                                                 | #15          |
